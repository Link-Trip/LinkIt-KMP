## 한눈에 보기

온보딩 플로우는 앱을 처음 설치한 사용자가 "여행 영상 하나로 일정이 만들어진다"는 핵심 가치를 30초 안에 직접 체험하도록 이끄는 흐름이다. 설명만 읽는 온보딩이 아니라, 실제 메인 화면 위에서 안내 말풍선을 따라 버튼을 누르고 추천 영상 링크를 복사해 붙여넣어 첫 일정을 만들어 보는 체험형 튜토리얼이다. 원하지 않는 사용자는 어느 단계에서든 건너뛰고 바로 메인 화면으로 갈 수 있다.

| 단계 | 화면 | 사용자가 하는 일 | 결과 |
|---|---|---|---|
| 1. 인트로 애니메이션 | 지구 아이콘 애니메이션 | 기다림 | 최초 진입이면 온보딩 시작 화면, 아니면 메인 화면 |
| 2. 온보딩 시작 | 후킹 문구 + `30초 만에 사용법 보기` / `바로 시작하기` | 둘 중 하나 선택 | 약관 동의 바텀시트 |
| 3. 약관 동의 | `핑고를 시작하려면 동의가 필요해요` 바텀시트 | 필수 약관 2종 동의 후 `동의하고 시작하기` | 사용법 보기면 튜토리얼, 바로 시작이면 메인 화면 |
| 4. 튜토리얼: 일정 생성 안내 | 메인 지도 위 딤 처리 + 말풍선 | `일정 생성` 버튼 → `영상 링크로 만들기` 선택 | 영상 링크로 만들기 화면 |
| 5. 튜토리얼: 링크 복사·붙여넣기 | 영상 링크로 만들기 화면 + 말풍선 | 추천 영상 `링크복사` → `복사한 링크 붙여넣기` → `일정 생성하기` | 분석 완료 화면 |
| 6. 분석 완료 | `축하해요 첫일정 분석이 완료됐어요!` | `생성된 일정 확인하기` | 메인 화면(신규 일정이 `확인전` 상태로 강조) |
| 건너뛰기 | 시작 화면 `바로 시작하기`, 튜토리얼 화면 우상단 `건너뛰기` | 선택 | 메인 화면(저장 일정 없으면 빈 상태 안내) |

## Clarifications

### Session 2026-09-18

- Q: 온보딩 시작 화면에서 `30초 만에 사용법 보기`와 `바로 시작하기` 중 어느 버튼을 눌렀을 때 약관 동의 바텀시트가 나타나야 하는가? → A: 두 버튼 모두 약관 동의 바텀시트를 먼저 띄우고, 동의 후 각각 튜토리얼 또는 메인 화면으로 이동한다.
- Q: 튜토리얼에서 만들어진 첫 일정은 사용자의 추가 조작 없이 자동으로 `저장한 일정`에 저장되는가, 아니면 일정 상세에서 직접 저장해야 하는가? → A: 자동 저장. `생성된 일정 확인하기`를 누르면 메인 화면 `저장한 일정` 맨 위에 `확인전` 상태로 이미 들어가 있다.
- Q: 지구 아이콘 인트로 애니메이션은 앱을 실행할 때마다 재생되는가, 처음 설치 후 첫 실행에서만 재생되는가? → A: 매 실행마다 재생한다. 끝나면 온보딩 미완료 사용자는 온보딩 시작 화면, 완료 사용자는 메인 화면으로 간다.
- Q: 튜토리얼 중 안내가 풀린 뒤 사용자가 추천 영상이 아닌 다른 영상 링크를 직접 입력해 `일정 생성하기`를 누르면 어떻게 처리하는가? → A: 온보딩 중에는 추천 영상 링크만 허용한다. 다른 링크는 추천 영상을 사용하라는 안내 토스트를 띄우고 진행하지 않는다.
- Q: 온보딩의 추천 영상 목록과 미리 준비된 일정은 어디에서 오는가? → A: 서버가 제공한다. 앱은 목록과 준비된 일정을 받아오고, 못 받으면 안내와 `다시 시도`, `건너뛰기`만 가능하다.

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 최초 진입과 온보딩 시작·건너뛰기 (Priority: P1)

앱을 처음 설치한 사용자는 실행 직후 지구 아이콘 인트로 애니메이션을 본 뒤 온보딩 시작 화면에 도착한다. 화면에는 캐릭터 일러스트, `여행 영상, 이제 저장만 하지 마세요` 배지, `보고있던 여행 영상을 내 일정으로 만들어보세요!` 제목, `영상을 분석해 마커와 일정으로 정리해드릴게요 ⭐` 설명이 있고, 하단에 `30초 만에 사용법 보기`(강조)와 `바로 시작하기` 버튼이 있다. `바로 시작하기`를 고르면 약관 동의 후 곧바로 메인 화면으로 가고, 이후 앱을 다시 실행하면 인트로 애니메이션만 지나 메인 화면이 열린다.

**Why this priority**: 모든 신규 사용자가 반드시 거치는 관문이며, 이 스토리만 구현해도 "최초 진입 → 메인 화면" 경로와 온보딩 완료 상태의 저장이 성립해 독립적인 가치가 있다.

**Independent Test**: 앱을 새로 설치해 실행하고 인트로 애니메이션 뒤 온보딩 시작 화면이 뜨는지, `바로 시작하기` → 약관 동의 → 메인 화면 진입이 되는지, 앱을 완전히 종료하고 재실행했을 때 온보딩 시작 화면 없이 메인 화면이 열리는지 확인하면 검증된다.

**Acceptance Scenarios**:

1. **Given** 앱을 처음 설치한 상태, **When** 앱을 실행하면, **Then** 지구 아이콘 인트로 애니메이션이 재생된 뒤 온보딩 시작 화면이 표시된다.
2. **Given** 온보딩 시작 화면이 표시된 상태, **When** 화면을 보면, **Then** 캐릭터 일러스트, `여행 영상, 이제 저장만 하지 마세요` 배지, `보고있던 여행 영상을 내 일정으로 만들어보세요!` 제목, `영상을 분석해 마커와 일정으로 정리해드릴게요 ⭐` 설명, `30초 만에 사용법 보기`(강조) 버튼, `바로 시작하기` 버튼이 위에서 아래 순서로 보인다.
3. **Given** 온보딩 시작 화면이 표시된 상태, **When** `바로 시작하기`를 누르고 약관 동의를 마치면, **Then** 튜토리얼 없이 메인 화면이 열린다.
4. **Given** 저장된 일정이 하나도 없는 상태에서 `바로 시작하기`로 메인 화면에 진입한 상태, **When** 메인 화면을 보면, **Then** 하단 시트가 올라와 `저장된 일정이 없어요`, `여행 영상 하나면 핑고가 일정으로 만들어드려요!` 안내와 `일정 생성하기` 버튼, `볼만한 영상 찾아보기` 링크가 보인다.
5. **Given** 온보딩을 마쳤거나 건너뛴 상태, **When** 앱을 완전히 종료한 뒤 다시 실행하면, **Then** 인트로 애니메이션 뒤 온보딩 시작 화면 없이 메인 화면이 열린다.
6. **Given** 온보딩 시작 화면이 표시된 상태, **When** 시스템 뒤로가기를 누르면, **Then** 인트로 애니메이션으로 돌아가지 않는다. 시스템 뒤로가기가 있는 기기에서는 앱이 종료된다.
7. **Given** 마이페이지에서 앱 초기화를 완료한 상태, **When** 앱이 온보딩 시작 화면으로 이동하면, **Then** 첫 설치 때와 같은 온보딩 시작 화면이 표시되고 이후 흐름도 동일하게 동작한다.

### User Story 2 - 약관 동의 (Priority: P1)

온보딩 시작 화면에서 어느 버튼을 누르든 사용자는 먼저 약관 동의 바텀시트를 만난다. 시트에는 `핑고를 시작하려면 동의가 필요해요` 제목과 `필수 항목에 동의해야 서비스를 이용할 수 있어요` 설명, `전체 동의` 항목, `[필수] 서비스 이용약관 동의`와 `[필수] 개인정보 수집·이용 동의` 항목(각각 `상세보기` 링크), `동의하고 시작하기` 버튼이 있다. 필수 항목 두 개를 모두 체크해야 버튼이 활성화되고, `상세보기`를 누르면 해당 약관 전문을 앱 안에서 읽을 수 있다.

**Why this priority**: 서비스 이용 전 법적으로 필요한 동의 절차이며, 동의 없이는 튜토리얼과 메인 화면 어느 쪽으로도 진행할 수 없다.

**Independent Test**: 온보딩 시작 화면에서 버튼을 눌러 바텀시트를 열고, 개별 체크와 `전체 동의`의 연동, 버튼 활성 조건, `상세보기` 진입과 복귀, `동의하고 시작하기` 후 선택한 버튼에 맞는 목적지로 이동하는지 확인하면 검증된다.

**Acceptance Scenarios**:

1. **Given** 온보딩 시작 화면이 표시된 상태, **When** `30초 만에 사용법 보기` 또는 `바로 시작하기`를 누르면, **Then** 시작 화면이 어두워지고 그 위로 약관 동의 바텀시트가 올라온다. 시트에는 제목, 설명, `전체 동의`, 필수 약관 2개 항목(각각 `상세보기`), 비활성 `동의하고 시작하기` 버튼이 있다.
2. **Given** 바텀시트가 열린 직후, **When** 화면을 보면, **Then** 모든 체크 항목은 해제 상태이고 `동의하고 시작하기`는 비활성이다.
3. **Given** 바텀시트가 열린 상태, **When** `전체 동의`를 누르면, **Then** 필수 약관 2개가 모두 체크되고 `동의하고 시작하기`가 활성화된다. 다시 누르면 모두 해제되고 버튼은 비활성으로 돌아간다.
4. **Given** 바텀시트가 열린 상태, **When** 필수 약관 2개를 각각 눌러 모두 체크하면, **Then** `전체 동의`도 체크 상태로 바뀌고 `동의하고 시작하기`가 활성화된다. 둘 중 하나를 해제하면 `전체 동의`가 해제되고 버튼은 비활성으로 돌아간다.
5. **Given** 바텀시트가 열린 상태, **When** `상세보기`를 누르면, **Then** 상단에 뒤로가기와 해당 약관 제목(`서비스 이용약관` 또는 `개인정보 수집·이용 동의`)이 있는 상세 화면이 열리고 본문을 끝까지 스크롤해 읽을 수 있다. 뒤로가기를 누르면 체크 상태가 유지된 바텀시트로 돌아온다.
6. **Given** 필수 약관 2개가 체크되어 버튼이 활성화된 상태, **When** `동의하고 시작하기`를 누르면, **Then** 동의 사실이 기록되고, 시작 화면에서 `30초 만에 사용법 보기`를 골랐다면 튜토리얼 메인 화면으로, `바로 시작하기`를 골랐다면 메인 화면으로 이동한다.
7. **Given** 바텀시트가 열린 상태, **When** 시트를 아래로 끌어 내리거나 시트 밖 어두운 영역을 누르면, **Then** 시트가 닫히고 온보딩 시작 화면으로 돌아가며 아무것도 기록되지 않는다.
8. **Given** 약관 동의를 한 번 완료한 상태, **When** 이후 앱을 다시 실행하면, **Then** 약관 동의 바텀시트는 다시 표시되지 않는다.

### User Story 3 - 체험형 튜토리얼로 첫 일정 만들기 (Priority: P1)

`30초 만에 사용법 보기`를 고른 사용자는 메인 지도 화면 위에서 안내 말풍선을 따라간다. 화면이 어두워지고 `일정 생성 버튼을 선택해보세요` 말풍선이 `일정 생성` 버튼을 가리킨다. 버튼을 누르면 생성 방식 메뉴가 열리고 `"영상 링크로 만들기" 를 선택해보세요` 말풍선이 뜨며 나머지 방식은 비활성이다. 영상 링크로 만들기 화면에 들어가면 추천 영상이 보이고, 잠시 뒤 화면이 어두워지며 `링크를 복사해요` 말풍선이 `링크복사` 버튼을 가리킨다. 링크를 복사하면 `복사한 링크 붙여넣기` 칩이 활성화되고 `붙여넣어요~` 말풍선이 칩을 가리킨다. 붙여넣으면 입력란이 채워지고 `일정 생성하기`가 활성화된다. 누르면 `축하해요 첫일정 분석이 완료됐어요!` 화면이 뜬다.

**Why this priority**: 온보딩의 핵심 가치 전달 구간이다. 이 스토리로 사용자는 앱의 주요 조작(일정 생성 버튼 → 영상 링크 → 링크 복사·붙여넣기)을 실제로 눌러 보며 첫 일정을 얻는다.

**Independent Test**: `30초 만에 사용법 보기`로 튜토리얼에 진입해 말풍선 순서대로 5번의 조작(일정 생성, 영상 링크로 만들기, 링크복사, 복사한 링크 붙여넣기, 일정 생성하기)만으로 분석 완료 화면에 도달하는지, 안내 중 다른 영역을 눌러도 아무 일도 일어나지 않는지 확인하면 검증된다.

**Acceptance Scenarios**:

1. **Given** 약관 동의를 마치고 `30초 만에 사용법 보기` 경로로 진입한 상태, **When** 튜토리얼 메인 화면이 열리면, **Then** 지도, `일본, 도쿄` 지역 칩, `일정 생성` 버튼, 하단 탭(홈·보관함·탐색), 우상단 `건너뛰기` 버튼이 보이고, 곧이어 `일정 생성` 버튼과 `건너뛰기`만 밝게 남긴 채 화면이 어두워지며 `일정 생성 버튼을 선택해보세요` 말풍선이 `일정 생성` 버튼 위에 표시된다.
2. **Given** `일정 생성 버튼을 선택해보세요` 말풍선이 표시된 상태, **When** 어두워진 영역(지도, 하단 탭, 지역 칩 등)을 누르면, **Then** 아무 반응이 없고 말풍선은 유지된다.
3. **Given** `일정 생성 버튼을 선택해보세요` 말풍선이 표시된 상태, **When** `일정 생성` 버튼을 누르면, **Then** `영상 링크로 만들기`(활성), `보관함에서 가져오기`(비활성), `직접 만들기`(비활성) 메뉴와 닫기 버튼이 열리고 `"영상 링크로 만들기" 를 선택해보세요` 말풍선이 `영상 링크로 만들기` 위에 표시된다.
4. **Given** 생성 방식 메뉴가 열린 상태, **When** `보관함에서 가져오기`나 `직접 만들기`, 닫기 버튼, 그 밖의 어두운 영역을 누르면, **Then** 아무 반응이 없고 메뉴와 말풍선은 유지된다.
5. **Given** 생성 방식 메뉴가 열린 상태, **When** `영상 링크로 만들기`를 누르면, **Then** 영상 링크로 만들기 화면이 열린다. 화면에는 제목 `영상 링크로 만들기`, 우상단 `건너뛰기`, 안내 일러스트, `추천영상` 목록(썸네일·`링크복사` 버튼·제목·조회수), 비활성 `복사한 링크 붙여넣기` 칩, `영상 링크` 입력란(플레이스홀더 `URL 를 붙여넣거나 입력해주세요.`), 비활성 `일정 생성하기` 버튼이 있다.
6. **Given** 영상 링크로 만들기 화면이 열린 상태, **When** 짧은 시간이 지나면, **Then** 추천 영상의 `링크복사` 버튼과 `건너뛰기`만 밝게 남긴 채 화면이 어두워지고 `링크를 복사해요` 말풍선과 포인터가 첫 번째 추천 영상의 `링크복사`를 가리킨다.
7. **Given** `링크를 복사해요` 말풍선이 표시된 상태, **When** `링크복사`를 누르면, **Then** 그 영상의 링크가 클립보드에 복사되고 어두운 처리가 풀리며 `복사한 링크 붙여넣기` 칩이 활성화되고, 화면 하단에 `클립보드에 복사한 링크`와 복사된 링크 주소, 닫기 아이콘이 있는 토스트가 표시된다.
8. **Given** 링크가 복사된 상태, **When** 곧이어 안내가 이어지면, **Then** `복사한 링크 붙여넣기` 칩과 `건너뛰기`만 밝게 남긴 채 화면이 어두워지고 `붙여넣어요~` 말풍선과 포인터가 칩을 가리킨다.
9. **Given** `붙여넣어요~` 말풍선이 표시된 상태, **When** `복사한 링크 붙여넣기` 칩을 누르면, **Then** 어두운 처리가 풀리고 `영상 링크` 입력란에 복사한 링크가 채워지며 `일정 생성하기` 버튼이 활성화된다.
10. **Given** 클립보드 토스트가 표시된 상태, **When** 토스트 본문을 누르면, **Then** 그 링크가 `영상 링크` 입력란에 채워지고 토스트가 닫힌다. 닫기 아이콘을 누르면 입력 없이 토스트만 닫힌다.
11. **Given** 입력란에 유효한 추천 영상 링크가 채워진 상태, **When** `일정 생성하기`를 누르면, **Then** 캐릭터 일러스트와 `축하해요 첫일정 분석이 완료됐어요!`, `짜여진 일정을 저장하고 쉽게 관리해보세요` 문구, `생성된 일정 확인하기` 버튼이 있는 분석 완료 화면이 표시된다.
12. **Given** 어두운 처리가 풀려 자유롭게 조작할 수 있는 상태, **When** 입력란에 직접 링크를 입력하거나 수정하면, **Then** 공백 제외 1자 이상이면 `일정 생성하기`가 활성화되고 비어 있으면 비활성으로 돌아간다.
13. **Given** 입력란에 유효하지 않은 링크가 있는 상태, **When** `일정 생성하기`를 누르면, **Then** `유효한 영상 링크가 아닙니다` 토스트가 표시되고 버튼이 비활성으로 바뀌며, 링크를 수정하면 다시 활성화된다.
14. **Given** 입력란에 형식은 유효하지만 추천 영상 목록에 없는 영상 링크가 있는 상태, **When** `일정 생성하기`를 누르면, **Then** 일정은 생성되지 않고 `온보딩에서는 추천 영상 링크만 사용할 수 있어요` 토스트가 표시되며 버튼이 비활성으로 바뀌고, 링크를 수정하면 다시 활성화된다.
15. **Given** 튜토리얼의 어느 화면이든 표시된 상태, **When** 우상단 `건너뛰기`를 누르면, **Then** 튜토리얼이 즉시 종료되고 메인 화면으로 이동하며 온보딩은 완료로 기록된다.

### User Story 4 - 생성된 첫 일정 확인 (Priority: P2)

분석 완료 화면에서 `생성된 일정 확인하기`를 누르면 메인 화면으로 이동한다. 하단 `저장한 일정` 시트에 방금 만든 일정 카드가 아직 확인하지 않았다는 뜻의 강조 배경(`확인전`)으로 보이고, 지도에는 그 일정의 장소 마커와 일정 이름 말풍선이 표시된다. 카드를 누르면 일정 상세(여행 일정·영상 요약 탭)를 볼 수 있고, 돌아오면 카드는 일반 배경(`확인후`)으로 바뀐다. 이 시점에 온보딩은 완료로 기록된다.

**Why this priority**: 튜토리얼의 결과물을 사용자가 자기 것으로 확인하는 마무리 구간이다. US3 없이도 메인 화면의 `확인전/확인후` 표현은 독립적으로 검증 가능하다.

**Independent Test**: 분석 완료 화면에서 `생성된 일정 확인하기`를 눌러 메인 화면의 `저장한 일정`에 새 일정이 강조 배경으로 보이는지, 지도에 마커가 표시되는지, 카드를 열었다가 돌아오면 강조가 사라지는지, 앱 재실행 시 메인 화면이 바로 열리는지 확인하면 검증된다.

**Acceptance Scenarios**:

1. **Given** 분석 완료 화면이 표시된 상태, **When** `생성된 일정 확인하기`를 누르면, **Then** 메인 화면이 열리고 하단 `저장한 일정` 시트의 목록 맨 위에 방금 생성된 일정 카드가 강조 배경(`확인전`)으로 표시된다. 카드에는 썸네일, 여행 스타일 태그, 일정 이름, 기간, 예상 비용, 한 줄 요약, 더보기 아이콘이 있다.
2. **Given** 생성된 일정이 있는 메인 화면, **When** 지도를 보면, **Then** 일정에 포함된 장소들의 썸네일 마커와 일정 이름 말풍선(`도쿄 신주쿠 여행 [테스트]` 형식)이 표시된다.
3. **Given** `확인전` 카드가 보이는 상태, **When** 카드를 누르면, **Then** 일정 상세가 열려 `여행 일정` 탭(박수·일차 칩·장소 카드)과 `영상 요약` 탭(영상 정보·AI 요약·태그·여행 정보·타임라인)을 볼 수 있다.
4. **Given** 일정 상세를 열었다가 뒤로가기로 돌아온 상태, **When** `저장한 일정` 목록을 보면, **Then** 그 카드는 일반 배경(`확인후`)으로 표시되고 이후 다시 강조되지 않는다.
5. **Given** `저장한 일정` 시트가 표시된 상태, **When** 시트를 위로 끌어 올리면, **Then** 시트가 전체 화면 목록으로 확장되고 `확인전` 카드는 목록 안에서도 같은 강조 배경으로 보인다.
6. **Given** 생성된 일정을 확인한 상태, **When** 앱을 완전히 종료하고 다시 실행하면, **Then** 인트로 애니메이션 뒤 메인 화면이 바로 열리고 생성된 일정은 `저장한 일정`에 그대로 남아 있다.
7. **Given** 분석 완료 화면이 표시된 상태, **When** 시스템 뒤로가기를 누르면, **Then** 영상 링크로 만들기 화면으로 돌아가지 않고 분석 완료 화면이 유지된다.

### Edge Cases

- 인트로 애니메이션 재생 중 앱이 백그라운드로 갔다가 돌아오면 애니메이션이 끝난 뒤 정상 목적지(온보딩 시작 또는 메인)로 이동하며, 같은 실행에서 두 번 이동하지 않는다.
- 약관 동의 전에 앱을 종료하면 다음 실행에서 다시 온보딩 시작 화면부터 시작하고 체크 상태는 남지 않는다.
- 약관 `상세보기` 본문을 불러오지 못하면(네트워크 없음 등) 빈 화면 대신 안내와 `다시 시도` 수단을 보여주고, 뒤로가기로 바텀시트에 돌아올 수 있다. 본문을 읽지 못해도 동의 체크는 가능하다.
- 튜토리얼 도중(어느 단계든) 앱을 종료하면 다음 실행에서는 온보딩 시작 화면부터 다시 시작한다. 중간 단계는 저장하지 않는다.
- 튜토리얼의 어두운 안내 단계에서 시스템 뒤로가기를 누르면 아무 일도 일어나지 않는다. 튜토리얼을 벗어나는 방법은 `건너뛰기`뿐이다.
- 추천 영상 목록을 불러오지 못하면 추천 영역에 불러오지 못했다는 안내와 `다시 시도`를 보여주고, 안내 말풍선 단계는 시작하지 않는다. 온보딩에서는 추천 영상 링크만 허용하므로 목록이 없는 동안 사용자는 `다시 시도`하거나 `건너뛰기`할 수 있다.
- `링크복사`를 눌렀는데 클립보드 접근이 거부되거나 실패하면 `복사한 링크 붙여넣기` 칩은 비활성으로 남고 토스트는 표시되지 않으며, 사용자는 링크를 직접 입력할 수 있다.
- 사용자가 앱 밖에서 복사한 텍스트가 클립보드에 있어도 `클립보드에 복사한 링크` 토스트는 표시되지 않는다. 토스트는 앱 안에서 `링크복사`로 복사한 경우에만 뜬다. 단 `복사한 링크 붙여넣기` 칩은 클립보드에 텍스트가 있으면 활성이다.
- 붙여넣은 내용이 링크 형식이 아니면 입력란에는 그대로 채워지되 `일정 생성하기`를 눌렀을 때 `유효한 영상 링크가 아닙니다` 토스트가 뜬다.
- 추천 영상 링크를 사용자가 일부 고쳐 넣어(예: 뒤에 다른 글자 추가) 추천 영상과 일치하지 않게 되면 추천 영상 링크로 인정하지 않고 안내 토스트를 띄운다. 같은 영상을 가리키는 주소 표기 차이(짧은 주소, 추가 매개변수 등)는 같은 링크로 인정한다.
- 추천 영상 링크로 `일정 생성하기`를 눌렀는데 미리 준비된 일정을 가져오지 못하면(네트워크 없음 등) 실패 안내와 `다시 시도`를 보여주고 영상 링크로 만들기 화면에 머문다.
- `일정 생성하기`를 연속으로 누르면 한 번만 처리되고 처리 중에는 버튼을 다시 누를 수 없다.
- 안내 말풍선이 표시되기 전 짧은 대기 시간 동안 사용자가 이미 대상 버튼을 눌렀다면, 그 단계는 완료된 것으로 보고 다음 단계 안내로 넘어간다.
- 온보딩 완료 후 `저장한 일정`에서 생성된 일정을 삭제해도 온보딩은 다시 시작되지 않는다. 온보딩 재시작은 앱 초기화로만 가능하다.
- 화면이 작은 기기에서는 온보딩 시작 화면과 약관 동의 바텀시트의 하단 버튼이 항상 보이고, 본문은 스크롤로 읽을 수 있다.

## Requirements *(mandatory)*

### Functional Requirements

**진입과 온보딩 상태**

- **FR-001**: 앱을 실행할 때마다 지구 아이콘 인트로 애니메이션을 먼저 표시해야 한다. 애니메이션이 끝나면 온보딩 미완료 사용자는 온보딩 시작 화면으로, 완료 사용자는 메인 화면으로 이동해야 한다.
- **FR-002**: 온보딩 완료 여부는 기기에 저장되어 앱 재실행 후에도 유지되어야 하며, 다음 세 경우에 완료로 기록해야 한다: `바로 시작하기`로 메인 화면 진입, 튜토리얼 중 `건너뛰기`, 분석 완료 화면에서 `생성된 일정 확인하기`.
- **FR-003**: 온보딩 완료 여부와 약관 동의 기록은 앱 초기화 시 함께 지워져 첫 설치 상태로 돌아가야 한다.
- **FR-004**: 온보딩 시작 화면에는 캐릭터 일러스트, 배지 `여행 영상, 이제 저장만 하지 마세요`, 제목 `보고있던 여행 영상을 내 일정으로 만들어보세요!`, 설명 `영상을 분석해 마커와 일정으로 정리해드릴게요 ⭐`, 강조 버튼 `30초 만에 사용법 보기`, 보조 버튼 `바로 시작하기`가 있어야 한다.

**약관 동의**

- **FR-005**: 온보딩 시작 화면의 두 버튼 중 어느 것을 눌러도 먼저 약관 동의 바텀시트를 표시해야 하며, 동의 완료 전에는 튜토리얼이나 메인 화면으로 진행할 수 없어야 한다.
- **FR-006**: 바텀시트에는 제목 `핑고를 시작하려면 동의가 필요해요`, 설명 `필수 항목에 동의해야 서비스를 이용할 수 있어요`, `전체 동의` 항목, `[필수] 서비스 이용약관 동의`와 `[필수] 개인정보 수집·이용 동의` 항목(각각 `상세보기`), `동의하고 시작하기` 버튼이 있어야 한다.
- **FR-007**: 모든 체크 항목은 해제 상태로 시작해야 한다. `전체 동의`는 필수 항목 전체를 한 번에 체크·해제하고, 필수 항목이 모두 체크되면 `전체 동의`도 체크 상태로, 하나라도 해제되면 `전체 동의`도 해제 상태로 동기화되어야 한다.
- **FR-008**: `동의하고 시작하기`는 필수 항목 2개가 모두 체크된 경우에만 활성화되어야 한다.
- **FR-009**: `상세보기`를 누르면 뒤로가기와 약관 제목이 있는 상세 화면에서 해당 약관 전문을 앱 안에서 읽을 수 있어야 하며, 뒤로가기로 돌아왔을 때 체크 상태가 유지되어야 한다. 본문을 불러오지 못하면 안내와 `다시 시도` 수단을 보여야 한다.
- **FR-010**: `동의하고 시작하기`를 누르면 동의 사실과 시각을 기기에 기록하고, 사용자가 시작 화면에서 고른 버튼에 따라 튜토리얼 메인 화면(`30초 만에 사용법 보기`) 또는 메인 화면(`바로 시작하기`)으로 이동해야 한다.
- **FR-011**: 바텀시트를 끌어 내리거나 바깥 영역을 누르면 시트가 닫히고 온보딩 시작 화면으로 돌아가야 하며 아무것도 기록되지 않아야 한다.

**튜토리얼 공통**

- **FR-012**: 튜토리얼의 안내 단계는 대상 버튼과 `건너뛰기` 버튼만 밝게 남기고 나머지 화면을 어둡게 처리한 뒤 말풍선(필요 시 포인터 포함)으로 대상 버튼을 가리켜야 한다. 어두운 영역과 비활성 요소는 눌러도 아무 반응이 없어야 하고, 시스템 뒤로가기도 무시되어야 한다.
- **FR-013**: 튜토리얼의 모든 화면 우상단에는 `건너뛰기` 버튼이 있어야 하며, 어느 단계에서 눌러도 즉시 튜토리얼을 종료하고 메인 화면으로 이동하며 온보딩을 완료로 기록해야 한다.
- **FR-014**: 안내 단계는 정해진 순서(일정 생성 버튼 → 영상 링크로 만들기 → 링크복사 → 복사한 링크 붙여넣기)로만 진행되어야 하고, 각 단계는 대상 버튼을 눌러야만 다음 단계로 넘어가야 한다.
- **FR-015**: 튜토리얼 중간에 앱이 종료되면 중간 상태를 저장하지 않고 다음 실행에서 온보딩 시작 화면부터 다시 시작해야 한다.

**튜토리얼: 일정 생성 안내**

- **FR-016**: 튜토리얼 메인 화면은 실제 메인 화면과 같은 구성(지도, 지역 칩, `일정 생성` 버튼, 하단 탭)에 `건너뛰기` 버튼을 더한 형태여야 하며, 진입 후 곧바로 `일정 생성 버튼을 선택해보세요` 말풍선 안내를 시작해야 한다.
- **FR-017**: `일정 생성` 버튼을 누르면 `영상 링크로 만들기`, `보관함에서 가져오기`, `직접 만들기` 메뉴와 닫기 버튼이 열리고 `"영상 링크로 만들기" 를 선택해보세요` 말풍선을 표시해야 한다. 튜토리얼 중에는 `영상 링크로 만들기`만 활성이고 나머지 두 방식과 닫기 버튼은 비활성이어야 한다.

**튜토리얼: 영상 링크로 만들기**

- **FR-018**: 영상 링크로 만들기 화면에는 제목 `영상 링크로 만들기`, `건너뛰기`, 안내 일러스트, `추천영상` 가로 목록, `복사한 링크 붙여넣기` 칩, `영상 링크` 입력란(플레이스홀더 `URL 를 붙여넣거나 입력해주세요.`), `일정 생성하기` 버튼이 있어야 한다.
- **FR-019**: 온보딩에서 진입한 영상 링크로 만들기 화면의 추천 영상은 서비스(서버)가 제공하는 전체 탐색 영상 목록 중 앞에서 8개만 노출해야 하며, 앱은 화면 진입 시 목록을 서비스에서 받아와야 한다. 노출되는 영상은 서비스가 미리 분석을 끝내 둔 것을 전제로 한다. 각 카드에는 썸네일, `링크복사` 버튼, 제목(한 줄 말줄임), 조회수가 있어야 한다. 목록을 받아오는 동안에는 추천 영역에 불러오는 중임을 표시하고, 받아오지 못하면 안내와 `다시 시도`를 보여야 한다.
- **FR-020**: 화면 진입 후 짧은 대기 시간이 지나면 `링크를 복사해요` 말풍선과 포인터로 첫 번째 추천 영상의 `링크복사`를 안내해야 한다.
- **FR-021**: `링크복사`를 누르면 해당 영상 링크를 클립보드에 복사하고, 화면 하단에 `클립보드에 복사한 링크` 제목과 복사된 주소, 닫기 아이콘이 있는 토스트를 표시해야 한다. 토스트 본문을 누르면 그 주소가 `영상 링크` 입력란에 채워지고, 닫기 아이콘은 토스트만 닫아야 한다. 이 토스트는 앱 안에서 복사한 경우에만 표시해야 한다.
- **FR-022**: `복사한 링크 붙여넣기` 칩은 클립보드에 텍스트가 없으면 비활성, 있으면 활성이어야 하며, 누르면 클립보드 내용을 `영상 링크` 입력란에 채워야 한다.
- **FR-023**: 링크 복사가 끝나면 `붙여넣어요~` 말풍선과 포인터로 `복사한 링크 붙여넣기` 칩을 안내해야 하고, 칩을 누르면 어두운 처리를 풀고 이후에는 사용자가 화면을 자유롭게 조작할 수 있어야 한다.
- **FR-024**: `영상 링크` 입력란은 글자 수 제한 없이 자유 입력을 허용해야 한다. `일정 생성하기`는 처음에 비활성이고, 입력란에 공백 제외 1자 이상이 있으면 활성, 비면 비활성이어야 한다.
- **FR-025**: `일정 생성하기`를 눌렀을 때 링크가 유효한 영상 링크가 아니면 `유효한 영상 링크가 아닙니다` 토스트를 표시하고 버튼을 비활성으로 바꾸며, 입력란 내용이 바뀌면 다시 활성화해야 한다.
- **FR-026**: 온보딩 중 `일정 생성하기`는 추천 영상 목록에 있는 영상의 링크만 받아들여야 한다. 추천 영상 링크면 분석 중 화면 없이 곧바로 미리 준비된 일정으로 분석 완료 화면을 표시하고, 형식은 유효하지만 추천 영상이 아닌 링크면 일정을 생성하지 않고 `온보딩에서는 추천 영상 링크만 사용할 수 있어요` 토스트를 표시한 뒤 버튼을 비활성으로 바꾸며 입력란 내용이 바뀌면 다시 활성화해야 한다. 같은 영상을 가리키는 주소 표기 차이는 같은 링크로 인정해야 한다. 처리 중에는 버튼을 중복으로 누를 수 없어야 한다.

**분석 완료와 생성된 일정 확인**

- **FR-027**: 분석 완료 화면에는 캐릭터 일러스트, `축하해요 첫일정 분석이 완료됐어요!`, `짜여진 일정을 저장하고 쉽게 관리해보세요` 문구, `생성된 일정 확인하기` 버튼이 있어야 하며, 시스템 뒤로가기로 이전 화면에 돌아갈 수 없어야 한다.
- **FR-028**: 온보딩에서 생성된 일정은 사용자의 추가 조작 없이 `저장한 일정`에 저장되어야 하며, 이름은 `국가/도시 + x박x일 + 여행 스타일` 규칙(예: `일본 오사카 3박4일 맛집투어`)으로 정해져야 한다.
- **FR-029**: `생성된 일정 확인하기`를 누르면 메인 화면으로 이동해 `저장한 일정` 시트 목록 맨 위에 생성된 일정을 `확인전` 강조 배경으로 표시하고, 지도에 그 일정의 장소 마커와 일정 이름 말풍선을 표시해야 한다. 이때 온보딩을 완료로 기록해야 한다.
- **FR-030**: 사용자가 아직 열어 보지 않은 신규 생성 일정은 `저장한 일정` 시트와 확장 목록 모두에서 `확인전` 강조 배경으로 표시하고, 상세를 한 번 열면 `확인후` 일반 배경으로 바꿔 이후 다시 강조하지 않아야 한다.
- **FR-031**: `확인전` 카드를 누르면 기존 일정 상세(여행 일정 탭·영상 요약 탭)가 열려야 하며, 뒤로가기로 메인 화면에 돌아오면 저장된 일정의 장소 마커가 지도에 유지되어야 한다.

### Key Entities

- **온보딩 상태 (Onboarding State)**: 기기에 하나만 존재하는 최초 진입 상태. 온보딩 완료 여부와 완료 방식(바로 시작, 건너뛰기, 튜토리얼 완료)을 가진다. 앱 초기화 때 첫 설치 상태로 돌아간다.
- **약관 동의 기록 (Terms Consent)**: 필수 약관 2종(서비스 이용약관, 개인정보 수집·이용)에 대한 동의 여부와 동의 시각. 온보딩 상태와 함께 기기에 저장되고 앱 초기화 때 지워진다.
- **튜토리얼 단계 (Tutorial Step)**: 체험형 튜토리얼의 진행 위치. 일정 생성 버튼 안내 → 영상 링크로 만들기 안내 → 링크복사 안내 → 붙여넣기 안내 → 자유 조작 순서를 가지며, 각 단계는 대상 버튼과 말풍선 문구를 가진다. 세션 안에서만 유지되고 저장되지 않는다.
- **추천 영상 (Recommended Video)**: 서비스(서버)의 전체 탐색 영상 목록 중 앞에서 8개. 서비스가 미리 분석을 끝내 둔 영상인 것을 전제로 하며, 앱에 내장하지 않고 화면 진입 시 받아온다. 썸네일, 제목, 조회수, 영상 링크를 가지며, 이 링크로 생성하면 분석 대기 없이 일정이 만들어진다. 온보딩 중 `일정 생성하기`가 받아들이는 유일한 링크 집합이다.
- **생성된 일정 (Generated Schedule)**: 영상 링크로 만들어진 여행 일정. 이름(`국가/도시 + x박x일 + 여행 스타일`), 썸네일, 여행 스타일 태그, 기간, 예상 비용, 한 줄 요약, 장소 목록, 확인 여부(`확인전`/`확인후`)를 가진다. 여행 스타일 표기는 `맛집 중심→맛집투어`, `쇼핑 중심→쇼핑투어`, `명소 탐방 중심→명소투어`, `자연·풍경 위주→자연탐방`, `문화·역사 탐방→문화탐방`, `액티비티→액티비티 여행`, `힐링→힐링 여행` 규칙을 따른다.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 처음 사용하는 사용자가 `30초 만에 사용법 보기`를 누른 뒤 안내 말풍선만 따라 5번의 탭으로 분석 완료 화면에 도달하며, 안내 시작부터 완료까지 60초 이내에 끝난다.
- **SC-002**: 온보딩을 원하지 않는 사용자는 온보딩 시작 화면에서 약관 동의를 포함해 4번 이하의 탭으로 메인 화면에 도달한다.
- **SC-003**: 온보딩을 완료하거나 건너뛴 사용자에게 이후 100회 재실행 동안 온보딩 시작 화면과 약관 동의 바텀시트가 다시 표시되는 경우가 0회다.
- **SC-004**: 필수 약관 중 하나라도 동의하지 않은 상태에서 튜토리얼이나 메인 화면으로 진입한 사례가 0건이다.
- **SC-005**: 튜토리얼의 어두운 안내 단계에서 대상 버튼과 `건너뛰기` 외의 조작으로 화면이 바뀌거나 튜토리얼을 벗어난 사례가 0건이다.
- **SC-006**: 추천 영상 링크로 `일정 생성하기`를 누른 뒤 2초 이내에 분석 완료 화면이 표시된다.
- **SC-007**: `생성된 일정 확인하기`를 누른 뒤 메인 화면에서 생성된 일정이 `저장한 일정` 맨 위에 `확인전` 강조로 보이고 지도에 마커가 표시되는 비율이 100%다.
- **SC-008**: 튜토리얼에 진입한 사용자 중 70% 이상이 `건너뛰기` 없이 분석 완료 화면까지 도달한다.

## Assumptions

- **인트로 애니메이션 재생 조건**: 디자인 설명에는 "최초 진입시 애니메이션 노출"로만 적혀 있다. 현재 앱은 실행 때마다 인트로 화면을 잠시 보여준 뒤 메인으로 넘어가므로, 이 스펙은 매 실행 시 재생하고 목적지만 온보딩 완료 여부로 나눈다. Clarifications에서 확정했다. 애니메이션 길이는 디자인에서 미정(`~ms`)이며 현재 구현값을 기본으로 두고 디자인 확정 시 조정한다. Figma 메모의 "지구가 줌인되며 내 위치로 확장" 연출과 위치 권한 fallback은 질문형 메모로 남아 있어 이 스펙 범위에 넣지 않는다.
- **약관 동의 시점**: Figma 연결선은 온보딩 시작 화면의 두 버튼에서 각각 약관 동의 바텀시트와 메인 화면으로 이어지지만, 바텀시트 제목이 `핑고를 시작하려면 동의가 필요해요`이므로 두 경로 모두 동의를 거친다. Clarifications에서 확정했다.
- **시작 버튼 문구**: 디자인 설명(`인트로 01`)은 `30초 만에 확인해보기`라고 적었으나 화면 시안은 `30초 만에 사용법 보기`다. 화면 시안을 기준으로 한다. 마이페이지 스펙(001)의 앱 초기화 가정에 적힌 `30초 만에 확인해보기`, `30초면 충분해요` 문구도 이 화면 시안으로 대체한다.
- **말풍선 문구**: 디자인 설명은 `링크를 복사해서 넣어보세요`라고 적었으나 화면 시안은 `링크를 복사해요`, `붙여넣어요~`다. 화면 시안을 기준으로 한다.
- **추천 영상 링크만 허용**: 튜토리얼 안내가 풀린 뒤에도 입력란에는 자유롭게 입력할 수 있지만, 온보딩 중 `일정 생성하기`는 추천 영상 링크만 받아들인다. Clarifications에서 확정했다. 따라서 온보딩 안에서는 실제 영상 분석과 분석 중 화면이 필요 없으며, 온보딩 섹션에 분석 중 화면이 없는 것과도 맞는다. 추천 영상이 아닌 링크에 띄우는 토스트 문구 `온보딩에서는 추천 영상 링크만 사용할 수 있어요`는 시안에 없는 새 문구이므로 디자인 확인이 필요하다.
- **생성된 일정 자동 저장**: 디자인 설명(`인트로`)의 "생성된 일정 확인하기 선택시 메인화면 진입"과 "신규 생성된 일정중 확인하지 않은 일정은 2-1과 같이 표현"을 근거로, 온보딩에서 만든 일정은 별도 저장 조작 없이 `저장한 일정`에 들어간다. Clarifications에서 확정했다. 같은 설명의 "일정을 저장하지 않고 이탈하면 지도에 노출되지 않음"은 일반 일정 생성 흐름의 규칙으로 해석했다.
- **`[테스트]` 표기**: 시안의 일정 이름 `도쿄 신주쿠 여행 [테스트]`는 예시 데이터이며 실제 이름은 `국가/도시 + x박x일 + 여행 스타일` 규칙(Figma `저장한 일정 이름 지정되는 구조` 섹션)을 따른다.
- **약관 본문 출처**: 약관 전문은 마이페이지 스펙(001)과 동일하게 운영 측이 관리하는 웹페이지를 앱 안에서 열어 보여준다. 온보딩의 `상세보기`는 그중 `서비스 이용약관`과 `개인정보 처리방침`을 연다. Figma의 약관 본문은 `(예시)` 자리 표시 문서다.
- **클립보드 토스트 예시**: 시안의 토스트에 적힌 메일 주소 링크는 예시이며, 실제로는 `링크복사`로 복사한 영상 링크가 표시된다.
- **추천 영상 출처**: 추천 영상 목록과 준비된 일정은 서버가 제공하며 앱에 내장하지 않는다. Clarifications에서 확정했다. 운영 측이 추천 영상을 바꿔도 앱 업데이트가 필요 없고, 네트워크가 없으면 튜토리얼은 `다시 시도`나 `건너뛰기`로만 진행된다. 온보딩 전용 목록은 두지 않고, 기존 영상 탐색 목록(필터 없음 = 전체)의 앞 8개를 추천 영상으로 쓴다(2026-09-21 확정). 이 영상들의 사전 분석은 운영이 보장한다.
- **위치 권한**: 인접한 `GPS` 섹션(2026-08-08)은 GPS 버튼 최초 선택 시 권한 요청과 동작을 정의하며 온보딩 중에는 위치 권한을 요청하지 않는다. 튜토리얼 메인 화면의 지도는 권한 없이 기본 지역(`일본, 도쿄` 시안 기준)을 보여준다.
- **메인 화면·일정 상세 의존**: 튜토리얼 메인 화면, `저장한 일정` 시트, 빈 상태 안내, 일정 상세(여행 일정·영상 요약 탭)의 세부 동작은 메인 지도·일정 기능이 소유하며, 이 스펙은 온보딩이 그 화면에 요구하는 것(건너뛰기 버튼, 딤 처리·말풍선 오버레이, `확인전/확인후` 표현)만 정의한다.
- **기존 구현과의 차이**: 현재 앱에는 지구 아이콘 인트로 화면(일정 시간 뒤 메인으로 자동 이동)과 일정 기능의 분석 중·분석 완료·일정 상세 화면이 있다. 온보딩 시작 화면, 약관 동의 바텀시트, 튜토리얼 오버레이, 온보딩용 영상 링크로 만들기 화면 구성(추천 영상·클립보드 토스트·붙여넣기 칩)은 새로 필요하다. 기존 `docs/specs/onboarding-screen.md`(v0.1.2, 이전 노드 기준)의 `전체일정 저장하기/선택항목 저장하기`, `일정 생성중` 토스트, 삭제 팝업은 최신 시안(2026-03-12)에 없으므로 이 스펙에서 제외하고, TBD-01(인트로 건너뛰기)·TBD-05(온보딩 중 생성 방식 제한)는 이 스펙에서 결론을 낸다. 마이페이지(001, PR #48, 2026-09-21 머지)의 앱 초기화는 인트로 Activity를 태스크 초기화 상태로 다시 띄우며 완료 토스트 표시 여부를 함께 넘기므로, 온보딩 시작 화면이 그 토스트(`앱 초기화가 완료되었습니다.`)를 표시한다.
