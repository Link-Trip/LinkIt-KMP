## 1. 한눈에 보기

마이페이지는 지도 설정, 도움말/지원, 이용약관, 앱 설정 및 앱 초기화 기능을 제공하는 설정성 화면이다. Figma에는 기본/위성 지도 설정 선택과 앱 초기화 확인 팝업 상태가 함께 표현되어 있다.

sitemap에서는 이 흐름이 `프로필 페이지`로 표현되어 있고, Figma section 이름은 `마이페이지`다. 이 문서에서는 두 명칭을 같은 설정성 화면군으로 본다.

| 큰 덩어리 | 역할 |
|---|---|
| 지도 설정 | 기본 지도와 위성 지도 중 선택 |
| 도움말 & 지원 | 피드백 보내기, 버그 신고하기 |
| 이용약관 | 약관 확인 진입 |
| 앱 설정 | 앱 초기화 진입 |
| 초기화 확인 | 복구 불가 경고와 취소/초기화 액션 |

## 2. 화면 상태별 읽기

### 2.1 마이페이지 기본

![마이페이지 기본](/Users/yuhohyeon/Desktop/project/LinkIt-KMP/docs/specs/assets/mypage/mypage-default.png)

마이페이지 기본 상태다. `지도 설정` 아래에 `기본`, `위성` 선택 카드가 있고, 도움말/지원과 앱 설정 항목이 이어진다. 기본 진입 상태에서는 `기본` 지도 옵션이 선택된 것으로 보인다.

### 2.2 앱 초기화 확인

![앱 초기화 확인](/Users/yuhohyeon/Desktop/project/LinkIt-KMP/docs/specs/assets/mypage/mypage-preference-edit.png)

`앱 초기화` 선택 시 `정말 앱을 초기화 하시겠어요?`, `앱을 초기화하면 다시 복구할 수 없어요` 확인 팝업이 표시된다. 액션은 `이전으로 돌아가기`, `초기화`로 나뉜다.

### 2.3 지도 설정 결과 후보

![지도 설정 결과 후보](/Users/yuhohyeon/Desktop/project/LinkIt-KMP/docs/specs/assets/mypage/mypage-map-preview.png)

Figma에는 마이페이지 주변에 지도 탐색 화면도 배치되어 있다. 마이페이지의 지도 설정이 메인 지도 화면의 기본/위성뷰에 영향을 주는 흐름으로 해석되지만, 실제 저장 범위와 즉시 반영 여부는 확인이 필요하다.

## 3. 핵심 UX 규칙

| 규칙 | 내용 |
|---|---|
| 지도 타입 선택 | `기본`, `위성` 중 하나를 선택한다. |
| 앱 초기화 보호 | 초기화는 즉시 실행하지 않고 확인 팝업을 거친다. |
| 초기화 경고 | 초기화 시 복구 불가 문구를 명시한다. |
| 지원 액션 | 피드백 보내기, 버그 신고하기를 제공한다. |
| 진입 위치 | sitemap상 프로필 페이지 하위 설정 화면으로 해석한다. 하단 탭 루트 여부는 별도 확인 필요하다. |
