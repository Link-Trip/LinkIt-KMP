## 1. 한눈에 보기

탐색 & 피드 화면은 여행 영상과 크리에이터, 국가/테마 기반 추천 콘텐츠를 탐색하는 탭이다. 사용자는 국가별/테마별 탭을 전환하고, 인기 여행지, 인기 크리에이터, 많이 분석된 여행 영상을 훑는다.

Figma에는 영상 선택 시 유튜브로 이탈할지 앱 내부에서 보여줄지에 대한 질문형 메모가 있어, 영상 상세/재생 정책은 미정으로 분리한다.

| 큰 덩어리 | 역할 |
|---|---|
| 국가별 둘러보기 | 전체/일본/중국/베트남/아시아/유럽/북미 등 국가/권역 필터 |
| 테마별 둘러보기 | 미식 여행, 힐링 여행, 도심지 여행, 자연속 여행 등 테마 필터 |
| 인기 여행지 | Tokyo, Bangkok, Rome 등 목적지 카드 |
| 크리에이터 | 인기 여행 크리에이터와 추천 유튜버 |
| 영상 피드 | 많이 분석된 영상, 국가/테마별 추천 영상, 크리에이터별 영상 |

동일 section 안에 마이페이지/도움말/앱 초기화 계열 프레임도 일부 포함되어 있으나, 이 문서는 `탐색` 탭의 국가/테마/크리에이터/영상 탐색 흐름만 다룬다. 마이페이지 설정성 화면은 [mypage-screen.md](/Users/yuhohyeon/Desktop/project/LinkIt-KMP/docs/specs/mypage-screen.md)에서 별도로 정리한다.

## 2. 화면 상태별 읽기

### 2.1 탐색 기본

![탐색 기본](/Users/yuhohyeon/Desktop/project/LinkIt-KMP/docs/specs/assets/explore/explore-home.png)

기본 탐색 화면은 `국가별 둘러보기`, `테마별 둘러보기`, 인기 여행지, 인기 크리에이터, 많이 분석된 여행 영상을 세로 피드로 제공한다.

### 2.2 국가 필터 선택

![국가 필터 선택](/Users/yuhohyeon/Desktop/project/LinkIt-KMP/docs/specs/assets/explore/explore-country-tab.png)

국가/권역을 선택하면 화면 문구가 선택 국가 기준으로 바뀐다. Figma의 일본 선택 예시에서는 `🌏 일본 인기 여행지 둘러보기`, `일본 어디로 떠나볼까요?`, `일본여행, 이런 유튜버는 어때요?`, `많이 요약된 일본여행 영상`, `일본에서 인기있는 여행 영상`, `한국 사람들이 많이 분석한 일본관련 영상이에요`가 확인된다. 다른 국가의 문구 매핑은 동일 패턴으로 추정되지만 최종 정책 확인이 필요하다.

### 2.3 테마 필터 선택

![테마 필터 선택](/Users/yuhohyeon/Desktop/project/LinkIt-KMP/docs/specs/assets/explore/explore-theme-tab.png)

테마 탭에서는 `미식 여행`, `힐링 여행`, `도심지 여행`, `자연속 여행` 같은 테마 칩을 제공하고, `테마별 추천 영상`, `설정된 선호도에 따라 영상을 추천해요` 섹션에서 선택된 테마에 맞는 영상을 보여준다.

### 2.4 추천 여행 유튜버 목록

![추천 여행 유튜버](/Users/yuhohyeon/Desktop/project/LinkIt-KMP/docs/specs/assets/explore/recommended-creators.png)

`추천 여행 유튜버` 상세 목록 화면이다. 크리에이터명, 구독자 수, 영상 카드가 함께 노출된다.

## 3. 핵심 UX 규칙

| 규칙 | 내용 |
|---|---|
| 국가/테마 탭 | 국가별 둘러보기와 테마별 둘러보기는 동일 화면 내 상위 탐색 축이다. |
| 국가 선택 문맥 | 선택된 국가에 따라 섹션 제목과 영상 목록 문구가 변경된다. |
| 테마 선택 문맥 | 선택된 테마에 따라 추천 영상 리스트가 변경된다. |
| 크리에이터별 영상 | 설정된 선호도에 따라 크리에이터별 영상을 추천하는 섹션이 있다. |
| 더보기 | 크리에이터 섹션의 더보기는 추천 유튜버 목록으로 이동하는 흐름으로 보이나 전환 정책 확인이 필요하다. |
| 영상 선택 | 유튜브 외부 이동 또는 앱 내부 재생 정책은 미정이다. |
| 하단 탭 | 지도, 보관함, 탐색 탭 라벨이 노출된다. 전환 결과는 공통 내비게이션 정책과 함께 확인한다. |

## 4. 사용자 흐름

| 흐름 | 사용자가 하는 일 | 결과 |
|---|---|---|
| 탐색 진입 | 하단 `탐색` 탭 선택 | 탐색 기본 피드 표시 |
| 국가 선택 | 국가/권역 칩 선택 | 일본 선택 예시 기준 여행지/영상/크리에이터 섹션 갱신. 타 국가는 매핑 정책 필요 |
| 테마 선택 | 테마 탭 또는 테마 칩 선택 | 선택 테마 기준 추천 영상 표시 |
| 크리에이터 더보기 | `더보기` 선택 | 추천 여행 유튜버 목록으로 이동하는 흐름으로 추정 |
| 영상 보기 | 영상 카드 또는 `영상 보러가기` 선택 | 외부 유튜브 또는 앱 내부 재생 정책 필요 |
